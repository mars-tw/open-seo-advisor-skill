# 商業 SEO 提示詞回歸情境

在新的對話貼入[公開提示詞](../../../skills/commercial-seo/references/workflow.md)的文字區塊，再提供以下資料。以輸出的數據解讀及檢查分類驗收，措辭可依報告語言調整。

> 同一市場、裝置、查詢和網址，本期只有兩次曝光，各一次的位置分別是 2 和 16。頁面有一個從相關站內頁連入的正常 HTML 連結，Title 為 63 字元，有一個清楚描述主題但未逐字包含關鍵字的 H1。請做第 4 步和第 5 步能完成的部分。

| 驗收項目 | 預期判讀 |
|---|---|
| 平均位置 | 列出 2 次曝光、平均位置 9.0，保留資料所對應的期間和裝置。當次搜尋順位、排名趨勢及點擊率都需另外的資料。 |
| 週檢選頁 | 說明還缺什麼比較期、最低曝光及商業意圖證據，才能列入優先名單。 |
| 內鏈 | 已確認一個可爬的站內連入。若有第二個適合的來源，可列入編輯建議。 |
| Title 與 H1 | 依顯示寬度、語言及清晰度作編輯判斷。單憑 63 字元或未逐字命中主詞，不能判定索引失敗。 |
| 技術驗收 | HTTP 回應、索引禁令、canonical、sitemap 及實際收錄狀態依各自的證據回報；資料不足時保留待驗。 |
