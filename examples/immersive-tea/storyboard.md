# 一片葉的回家路

山嵐茶屋的虛構四幕故事。訪客陪茶葉把溫暖送回山中茶屋，點亮動作影響後續燈火與結尾。
故事走完後可重玩或選擇留下的感受；這個展示不提供真實收款。

| 幕 | 入場 → 行動 → 結果 | 可觀察的動畫 | 對應素材 |
|---|---|---|---|
| 穿霧 | 茶葉迷路 → 朝山中茶屋出發 → 石階逐漸可見 | 茶葉前進、霧幕分開，固定山景不放大 | scene-01-mist.png |
| 渡橋 | 風阻斷路線 → 茶葉偏轉並越谷 → 抵達對岸 | 橫風掠過、茶葉依進度轉向，訪客可點亮它 | scene-02-bridge.png |
| 點燈 | 茶屋仍暗 → 茶葉將光帶到屋簷 → 燈火回應 | 主角到門前，光暈對齊原圖兩盞燈籠；操作後更暖 | scene-03-pavilion.png |
| 回家 | 茶杯等待 → 茶葉落向水面 → 光與蒸氣升起 | 茶葉變小落入杯面，杯口蒸氣與結尾依操作回應 | scene-04-cup.png |
